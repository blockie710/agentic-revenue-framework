## 1. Program Snapshot (verified)
- **What it is:** GitHub Sponsors lets the community financially support open-source developers directly on GitHub. Open Collective is the parallel fiscal-host option for project treasuries.
- **Who is eligible:** Anyone who **contributes to an open-source project** and lives in a **supported region** (US included). No entity required — individuals apply on their **personal account**.
- **Fees:** GitHub does not charge platform fees on Sponsors; payment processing may apply.
- **Source of truth:** docs.github.com/en/sponsors · github.com/open-source/sponsors

## 2. Why This Is the "Apply Now" One
- It is the **lowest-friction, zero-dilution** funding path: no LLC, no website, no incorporation needed.
- Eligibility is tied to **public OSS repos** — which the founder already has.
- It compounds as an **always-open cushion**: small recurring monthly sponsorships that do not expire like credits.
